# todoapp

HTML, CSS, JavaScript만으로 만든 정적 웹 페이지 연습 프로젝트입니다.

## 현재 상태

지금은 자기소개 카드 페이지가 들어 있습니다. Todo 기능은 아직 구현되지 않았습니다.

- 이름, 직업, 아바타(이모지)를 보여주는 카드
- 취미 목록을 태그 형태로 표시
- `#667eea` → `#764ba2` 보라색 그라데이션 배경
- 모바일 화면에서도 보이는 반응형 레이아웃

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 구조 (카드, 이름, 직업, 취미 목록) |
| `style.css` | 카드 레이아웃과 색상 스타일 |
| `main.js` | 빈 `initApp()` 함수만 있으며, 아직 호출하는 곳이 없음 |

## 실행 방법

빌드 과정이나 설치할 패키지가 없습니다.

1. 저장소를 내려받습니다.
   ```
   git clone https://github.com/BaekHyoseol/todoapp.git
   ```
2. `index.html` 파일을 브라우저로 엽니다.

## 사용 기술

- HTML5
- CSS3 (Flexbox, 그라데이션)
- JavaScript (외부 라이브러리 없음)
